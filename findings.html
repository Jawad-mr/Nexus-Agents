F-024· Jul 22, 2026

Prompt caching cuts latency 40% on repeated agent calls

Across three production agents handling repeat-structure requests, enabling prompt caching on the system-prompt portion reduced average response time by roughly 40% with no measurable drop in output quality. The gain was largest on our Support Router agent, which reuses the same instruction block thousands of times a day.

F-023· Jul 18, 2026
High confidence

Smaller fine-tuned models outperform general models on narrow tasks

On our support-ticket routing task specifically, a smaller fine-tuned model matched or beat a much larger general-purpose model on accuracy, while running at roughly a third of the cost per call. The gap narrows on tasks requiring broader reasoning — this holds mainly for narrow, well-defined classification work.

F-022· Jul 13, 2026
Moderate confidence

Multi-agent handoff loses context past 3 hops without explicit state

When a task passes through more than three agents in sequence without an explicit shared state object, we observed a meaningful drop in task completion accuracy — agents downstream would occasionally re-ask for information already established earlier in the chain. Passing a structured state object between hops resolved most of this.

68%

Structured output formatting reduces downstream parsing errors by half

Switching agent outputs from free text to a constrained structured format cut downstream parsing failures roughly in half across our internal test suite. The remaining failures clustered around edge cases with nested optional fields.
