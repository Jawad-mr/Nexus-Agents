Nexus Agents API Reference

Integrate purpose-built autonomous agents directly into your backend architecture, CRM, or custom SaaS workflows using our REST API or JavaScript SDK.

Authentication Support Router API Data Extractor API Webhooks & Events Error Codes

1. Authentication

Authenticate your HTTP API requests by providing your secret API key in the request `Authorization` header.

# Include Bearer token in all HTTP headers
Authorization: Bearer nxs_live_9812401928401924

2. Support Router Endpoint (`POST /v1/agents/support-router/run`)

Triggers intent classification, urgency scoring, and target queue determination for an incoming ticket payload.

cURL Example

curl -X POST https://api.nexusagents.com/v1/agents/support-router/run \
  -H "Authorization: Bearer nxs_live_9812401928401924" \
  -H "Content-Type: application/json" \
  -d '{
    "ticket_id": "TICK-9042",
    "customer_id": "cust_44102",
    "raw_text": "I was billed twice for my Growth Tier subscription renewal yesterday."
  }'

200 OK Response Output

{
  "execution_id": "exec_8819024",
  "agent": "support-router",
  "status": "success",
  "latency_ms": 184,
  "data": {
    "intent": "Billing Duplicate Charge",
    "priority": "HIGH",
    "target_department": "Finance Tier 2",
    "confidence": 0.994,
    "suggested_reply": "Issue refund for transaction TX-88201."
  }
}

3. JavaScript SDK Integration

Install the official Nexus Agents SDK using npm or yarn for type-safe execution in Node.js applications.

// Node.js / TypeScript Example
import { NexusClient } from '@nexus-agents/sdk';

const nexus = new NexusClient({ apiKey: process.env.NEXUS_API_KEY });

const result = await nexus.agents.dataExtractor.extract({
  documentUrl: 'https://storage.acme.com/invoices/inv_2026.pdf',
  schema: 'invoice-v1'
});

console.log(result.data.extracted_entities);

4. Webhooks & Asynchronous Event Subscriptions

Configure webhook endpoints in your dashboard to receive real-time execution events for long-running agent tasks.

// Webhook Event Payload: agent.execution.completed
{
  "event": "agent.execution.completed",
  "timestamp": "2026-07-30T14:50:00Z",
  "agent": "lead-qualifier",
  "payload": {
    "lead_score": 95,
    "qualification": "Enterprise Target"
  }
}
